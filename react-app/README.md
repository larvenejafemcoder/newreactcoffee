# CyZerO - React Migration (Vite + TypeScript)

This project is a Vite + React + TypeScript scaffold created to migrate the existing static site into a React app.

Run locally:

1. cd react-app
2. npm install
3. npm run dev

What I migrated so far:
- Vite + TypeScript project scaffold
- Routing with React Router (Home and Showcase)
- Header and Hero components
- Core CSS files copied to `public/styles` so the site keeps its original look
